# Ralph Progress Log - Banking Expense Tracking

Branch: ralph/banking-expense-tracking
Started: 2026-01-17

## Codebase Patterns
- Use `t.references :user, null: false, foreign_key: true` for standard user FK
- Use `t.bigint :column_id, null: true` when referencing a table that doesn't exist yet
- Models follow pattern: belongs_to associations, validations, scopes
- Array indexes use spaces inside brackets per rubocop: `[ :user_id, :row_hash ]`
- Ruby 3.4 removed `csv` from stdlib - must add gem explicitly
- Services use Result struct pattern for returning structured results
- Pagination: Use Kaminari `.page(n).per(x)`, turbo_stream.replace for list component, Stimulus controller with spinner/content targets
- Filtering: Use plain HTML select() for dropdowns, form with turbo_stream data attribute, preserve filter params in ALL URL builders
- Debounce search: Create Stimulus controller with `search()` method that clears/sets timeout before calling `formTarget.requestSubmit()`
- ActionCable: Create channel in `app/channels/`, subscribe via Stimulus controller using `createConsumer()`, broadcast from jobs with `ActionCable.server.broadcast(channel_name, data)`
- FormDialog create/edit: Use `persisted?` to detect mode, dynamically set action/method/messages, add `_method: patch` hidden field for edits
- AlertDialog delete: AlertDialogTrigger wraps button, form with `data: { action: "submit@document->ruby-ui--alert-dialog#dismiss" }` inside AlertDialogFooter, use turbo_stream.remove for row deletion
- Bulk selection: Stimulus controller with selectAll/checkbox/bulkActions targets, hidden input with comma-separated IDs, controller returns array of turbo_stream.remove
- Nested feature controllers: Use `namespace :banking do resources :categories` for /banking/categories routes, controller in `app/controllers/banking/`
- Dialog internal navigation: Use turbo_stream.replace("content_area_id", NewComponent) to swap content without creating new dialogs
- Fuzzy string matching: Levenshtein distance algorithm in pure Ruby (no gems needed), similarity = (max_len - distance) / max_len
- Chart.js: `bin/importmap pin chart.js`, register only needed components (ArcElement, DoughnutController, etc.), pass data via Stimulus values
- Chart.js bar chart: Use BarElement, BarController, CategoryScale, LinearScale, datasets array with separate colors for multiple series
- PostgreSQL time grouping: Use DATE_TRUNC('week', column) or DATE_TRUNC('month', column) for aggregation
